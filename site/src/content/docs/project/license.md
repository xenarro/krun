**A license has not been published yet.**

The repository contains no `LICENSE` file, and none of its package manifests
(`package.json`, `sdk/python/pyproject.toml` or `deploy/helm/krun/Chart.yaml`)
declares a license. Choosing one is a decision for the project owner, and that
decision is still pending.

If you need to know the terms that apply to your use, ask the owner through
[GitHub issues](https://github.com/xenarro/krun/issues). This page will be updated
when a license is published.

## Third-party components

The libraries krun depends on, and the fonts this site uses, keep their own licenses.
